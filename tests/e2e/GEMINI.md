# End-to-End Playwright Verification Suites (`tests/e2e`)

This directory contains the sequential Playwright E2E test suites verifying the Optimis Host UI Shell, Sandboxed `<iframe sandbox="allow-scripts">` Plugin Bridge, Core DAL domain scoping, Backend Session/Persona Resolution, Safeguarding Vault Envelope Encryption, UK GDPR SAR Redaction & Retention Purge, and all 11 production plugin verticals.

The test suites are partitioned into 5 domain-aligned subdirectories to ensure clear separation of concerns, fast navigation, and streamlined maintenance.

---

## 1. Non-Negotiable E2E Test Standards

* **Sequential Execution**: Every spec file configures `test.describe.configure({ mode: 'serial' })` and runs with `--workers=1` via `npm test -- <test-name> local 1`.
* **Test Naming Convention**: Every test follows `methodname_initialstate_expectedbehaviour_test`.
* **Dual Log Tapping**: Every `beforeEach` / `afterEach` taps both:
  1. Browser console (`page.on('console')`) and uncaught page exceptions (`page.on('pageerror')`).
  2. Backend Go Host service logs (`GET /api/test/logs/cursor` and `GET /api/test/logs?since=...`).
* **Self-Contained Fixture & Plugin Lifecycle**: Every test seeds its own isolated SQLite records and runtime-installs/activates any required plugins (`POST /api/admin/plugins/install` -> `POST /api/admin/plugins/{id}/activate`) in `beforeEach`, and removes the plugin (`DELETE /api/admin/plugins/{id}`) and deletes seeded records in `afterEach` so zero test state leaks across runs.
* **Test Directory Discovery**: `playwright.config.ts` sets `testDir: './tests/e2e'`, enabling recursive discovery of all `.spec.ts` files across all subdirectories.
