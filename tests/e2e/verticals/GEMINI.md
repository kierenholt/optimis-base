# Production Plugin Verticals E2E Verification Suites (`tests/e2e/verticals`)

This directory contains full-stack Playwright E2E integration suites for the 11 production Optimis MIS plugin verticals, verifying end-to-end user workflows, method-level scoped RBAC, attached SQLite databases, UI bridge bindings, and UK GDPR lifecycle hooks.

---
