# Plugin Platform & SDK Toolchain E2E Verification Suites (`tests/e2e/platform`)

This directory contains sequential Playwright E2E integration suites for the Optimis Plugin Runtime Sandbox, `window.postMessage` RPC bridge, attached per-plugin SQLite databases, plugin lifecycle management, Plugin UI SDK & tokens, developer toolchain (`mis-verify`, `mis-test`, `mis-pack`, `mis-dev-server`), and the Widget Gallery layout bench.

---

## E2E Spec Files

* [`mvp_plugin.spec.ts`](file:///home/kieren/Documents/code/optimis/tests/e2e/platform/mvp_plugin.spec.ts):
  * Verifies the baseline `mis:init` and `mis:rpc:request` / `mis:rpc:response` `window.postMessage` bridge between the Host UI Shell and `uk.org.optimis.test`.
* [`plugin_attached_db.spec.ts`](file:///home/kieren/Documents/code/optimis/tests/e2e/platform/plugin_attached_db.spec.ts):
  * Verifies per-plugin attached SQLite persistence (`plugin_test.db`), `PRAGMA max_page_count` enforcement, and UK GDPR `export_pupil_data` / `purge_pupil_data` hooks.
* [`plugin_runtime_lifecycle.spec.ts`](file:///home/kieren/Documents/code/optimis/tests/e2e/platform/plugin_runtime_lifecycle.spec.ts):
  * Verifies Runtime Plugin Lifecycle management (`GET /api/admin/plugins`, `POST /api/admin/plugins/install`, `POST /api/admin/plugins/{plugin_id}/activate`, and `DELETE /api/admin/plugins/{plugin_id}`): RBAC enforcement rejecting non-Admin/DPO personas (`403 UNAUTHORIZED_ADMIN_PLUGIN_SCOPE`), installing a plugin into `UNINSTALLED_DORMANT` state with `plugin_<alias>.db` provisioned and attached, activating the plugin to expose its UI in `GET /api/system/ui-config` and enable RPC & Event Bus workers, and removing the plugin at runtime (stopping workers and detaching `plugin_<alias>.db`).
* [`plugin_ui_sdk_and_theming.spec.ts`](file:///home/kieren/Documents/code/optimis/tests/e2e/platform/plugin_ui_sdk_and_theming.spec.ts):
  * Verifies the Official Plugin UI SDK (`sdk/ui/mis-bridge.js`), Design Token & Theming System (`sdk/ui/mis-theme.css`, `--mis-*` Light & High-Contrast live toggling via Settings modal), Default Dashboard Layout chrome (`host-sidebar`, `host-dashboard-grid`), `window.mis.rpc()` Promise API resolution and fail-fast rejection, declarative `data-mis-link` Entity Deep-Linking (`student`, `group`), `connect-src 'none'` CSP enforcement inside `<iframe sandbox="allow-scripts">`, and caller-scoped `permitted_methods` filtering across `GET /api/system/ui-config` and `mis:init` (`window.mis.permittedMethods`).
* [`sdk_toolchain_10a_to_10d.spec.ts`](file:///home/kieren/Documents/code/optimis/tests/e2e/platform/sdk_toolchain_10a_to_10d.spec.ts):
  * Verifies Sections 8A–8C & 10A–10D Plugin Authoring SDK & Developer Toolchain end-to-end:
    * **10B VS Code & Schema Integration**: `.vscode/settings.json` (`Lua 5.1`, disabled globals, `.mis-types/dal.d.lua`, `sdk/manifest.schema.json`) and schema validation across all 11 production `manifest.json` files.
    * **10C Frontend Bridge Packages**: `@optimis/bridge` (`sdk/packages/bridge`), `@optimis/tailwind-preset` (`sdk/packages/tailwind-preset`), and `window.mis.useMisRpc` in `sdk/ui/mis-bridge.js`.
    * **10A Toolchain Binaries**: `bin/mis-verify` (passing on valid plugins and failing fast on undeclared UI `data-mis-rpc`, external `https://` CSP violations, `DROP COLUMN` migrations, and orphaned GDPR `purge_pupil_data` rows), `bin/mis-test` (executing `tests/*_test.lua` headlessly with structured stdout logs and non-zero failure exit codes), `bin/mis-pack` (running `mis-verify`, extracting Lucide `icon.svg`, and bundling deterministic `.mispkg` archives with `SIGNATURE.json`), and `bin/mis-dev-server` (`--dry-run` verification).
    * **10D Agent-First Observability, Persona Resolution & 27-Plugin DAL Readiness**: active session persona resolution via `POST /api/auth/persona` and `--persona` CLI flag, standalone `optimis-plugin-template` repository verification with `-trimpath` portable binaries, and full Lua DAL bindings & byte-identical `.mis-types/dal.d.lua` == `sdk/lua/ctx_types.lua` stubs across all 27 production plugin stories and all 11 Core DAL domains. Streamlined under 500 lines (477 lines) backed by [`sdk_toolchain_fixtures.ts`](file:///home/kieren/Documents/code/optimis/tests/e2e/platform/sdk_toolchain_fixtures.ts).
