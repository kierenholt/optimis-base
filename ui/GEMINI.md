# React Host UI Shell (`ui`)

This directory contains the Vite + React Single-Page Application (SPA) compiled into [`internal/host/ui_dist`](file:///home/kieren/Documents/code/optimis/internal/host/server.go#L18-L31) and embedded into the Go Host binary via `embed.FS`.

## Architectural Responsibilities

1. **Default School MIS Dashboard Layout, Narrow Icon Rail, Exclusive Right-Hand Pane View Switching & `--mis-*` Theme Engine ([`src/App.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/App.tsx), [`src/components/HostSidebar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostSidebar.tsx), [`src/views/DashboardSummaryStrip.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/views/DashboardSummaryStrip.tsx))**:
   - Renders the default UK All-Through School MIS workspace chrome: Left Sidebar **Narrow Icon Rail** (`data-testid="host-sidebar"`, `data-rail-mode="narrow-icon-rail"` containing strictly **Home** `data-testid="nav-rail-home"`, **Global Search** `data-testid="nav-rail-search"`, **Pinned Recents** `data-testid="nav-rail-pinned-recents"` persisted per persona in `staff_settings` with manual pin control `data-testid="topbar-pin-view-btn"`, **Settings** `data-testid="nav-rail-settings"`, and **Logout** `data-testid="nav-rail-logout"`, plus compact school identity `data-testid="host-school-name"`, with `<header data-testid="host-topbar">` completely removed) and the Responsive Right-Hand Content Pane (`data-testid="host-dashboard-grid"`).
   - Clicking any sidebar navigation button exclusively switches the right-hand content pane (`hostViewMode: 'home' | 'search' | 'settings' | 'plugin'`) without opening a modal: **Home** (`/`) renders `LandingPageTopHalfSearch`, `DashboardWidgetGridPanel`, and permitted DSL/Admin panels; **Search** (`/search`) renders `HostFullPageSearchView` (`data-testid="host-search-view"`); **Pinned / Plugin** (`/p/<plugid>...`) renders the active plugin in `KeepAlivePluginWorkspace`; and **Settings** (`/settings`) renders the full-page Host Settings View (`data-testid="host-settings-view"`, `data-testid="host-settings-theme-toggle-btn"`, and `data-testid="host-settings-font-size-control"`).
   - Fetches school branding, `--mis-*` theme catalogs (`light` & `high-contrast`), active plugin & widget descriptors (including monochrome Lucide `icon` names), per-persona `pinned_recents`, and entity link handler mappings from `GET /api/system/ui-config` ([`src/views/useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts)), waiting to mount plugin and widget `<iframe sandbox="allow-scripts">` instances until active installed plugins are resolved so uninstalled plugins never trigger 404 asset requests.
   - Applies `--mis-*` CSS Custom Properties and `data-mis-theme` onto `document.documentElement` (`:root`) and propagates live theme switches into all mounted child plugin and widget iframes without reloading.
2. **Cached Keep-Alive LRU Pool & Strict Opaque `/p/<plugid>` URL Routing (Section 9A, [`src/views/KeepAlivePluginWorkspace.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/views/KeepAlivePluginWorkspace.tsx), [`src/views/useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts), [`src/components/routeUtils.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/routeUtils.ts))**:
   - Keeps the last $N = 5$ (`MAX_KEEP_ALIVE_POOL_SIZE`) visited full-page plugin `<iframe sandbox="allow-scripts">` instances mounted inside `data-testid="keep-alive-lru-pool"` (`display: none` when inactive or when `hostViewMode !== 'plugin'`, `display: block` when active and `hostViewMode === 'plugin'`, `src="/p/<plugid>/ui/index.html"`) in stable DOM insertion order so tab switches never reload iframe state, and evicts the Least-Recently-Used (`lruPluginOrder[0]`) iframe when a 6th distinct plugin is visited.
   - Synchronizes every plugin view and its entity/tab state with the browser URL (`/p/<plugid>/<subpath>?<query>`) and validates direct browser navigation against `plugin.views[]` to render `data-testid="host-route-error-banner"` on undeclared paths, undeclared query parameters, or legacy `/plugins/*` URLs.
3. **Preset-Size Mini-Iframe Widget Grid & 1D `core.db` Persistence (Section 9B, [`src/DashboardWidgetGridPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/DashboardWidgetGridPanel.tsx), [`src/views/useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts))**:
   - Renders mini-iframe widgets declared in `manifest.json` (`widgets: [{ id, title, entry, width: 1 | 2, height: 1 | 2 }]`, served at `/p/<plugid>/ui/widget.html`) strictly at their declared `1x` or `2x` column width and `1x` or `2x` preset height inside an auto-flowing CSS grid (`data-testid="dashboard-widget-grid"`, `gridAutoFlow: 'row'` flowing left-to-right, top-to-bottom without arbitrary freeform resizing).
   - Keys all widget placement checks, reordering (`handleMoveWidgetUp`, `handleMoveWidgetDown`), removal (`handleRemoveWidget`), and catalog/search buttons by composite `plug_id + ":" + widget_id` (`getWidgetCompositeKey`) so widgets from different plugins sharing the same generic `widget.id` never collide.
   - Persists each caller's layout in `core.db` (`dashboard_layouts` via `GET`/`PUT /api/dashboard/layout`) as an **ordered 1D JSON array of `{ plug_id, widget_id }` objects**, supporting teacher ordering (`move-widget-up-btn-*`, `move-widget-down-btn-*`), placement/removal, Admin role defaults & append (`data-testid="admin-role-dashboard-controls"`, `PUT /api/admin/dashboard/role-default`, `POST /api/admin/dashboard/role-default/append`), and inline permission error cards (`data-testid="widget-permission-error-card-<widget_id>"`) when a saved widget's plugin or scope is revoked or unpermitted.
4. **Source-Aware Sandboxed `<iframe sandbox="allow-scripts">` RPC, Route Sync & Deep-Link Coordinator ([`src/components/useHostIframeBridge.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/useHostIframeBridge.ts), [`src/components/iframeMessageHandlers.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/iframeMessageHandlers.ts))**:
   - Maps `event.source` across all mounted Keep-Alive plugin iframes (`pluginIframeRefs` keyed by `plug_id`) and mini-iframe widgets (`widgetIframeRefs` keyed by composite `plug_id + ":" + widget_id`) back to the owning opaque `plug_id`.
   - Responds to `mis:ready` with `mis:init` containing `theme_mode`, `theme_tokens` (`--mis-*`), contextual route/entity parameters, `route` (`{ path, params, query }`), and caller-scoped `permitted_methods`.
   - Intercepts `mis:route:state` from child plugin iframes, validates the target path and query against `plugin.views[]`, updates `window.history.pushState`/`replaceState` to `/p/<plugid><path>?<query>`, and posts `mis:route:changed` back to the iframe.
   - Intercepts `mis:link:navigate` emitted by `[data-mis-link]` anchors inside any plugin or widget iframe (Section 9C), resolves the target plugin's opaque `plug_id` (`data-mis-plugin="self"` or `entity_link_handlers`), builds a clean target route (`/student/:pupil_id`, `/group/:group_id`, `/staff/:staff_id`), updates the browser URL to `/p/<targetPlugId>/...`, wakes the target plugin in the Keep-Alive LRU pool, and broadcasts `mis:init` and `mis:route:changed`.
   - Intercepts `mis:rpc:request` (`{ request_id, method, args }`), forwards authenticated requests to `POST /api/p/:plug_id/rpc/:method`, and posts `mis:rpc:response` back to the originating `event.source` window.
5. **Backend Session & Persona Resolution (Section 8A, [`src/views/useHostAdminAndDslState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostAdminAndDslState.ts))**:
   - Queries `GET /api/auth/personas` and `GET /api/auth/session` on mount (supporting test-only persona overrides via `?__persona=` URL param, `X-MIS-Persona` header, or `POST /api/auth/persona`, with zero in-UI persona switcher).
   - Switching personas (`Teacher`, `HoD`, `DSL`, `Admin/DPO`) fetches `GET /api/system/ui-config` and `GET /api/dashboard/layout` in parallel to update active plugin permitted method counts, per-persona `pinned_recents`, and per-persona 1D dashboard widget slots (including inline permission error cards), toggles the DSL Safeguarding Vault and Admin/DPO SAR Redaction consoles live, and broadcasts updated `mis:init` payloads to all mounted plugin and widget iframes.
6. **DSL Safeguarding Vault & OAuth Cloud Key Unlock Panel ([`src/SafeguardingVaultPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/SafeguardingVaultPanel.tsx))**:
   - Renders the Host-level DSL Safeguarding Vault (`data-testid="dsl-safeguarding-vault-panel"`) exclusively when the active session holds `dal.safeguarding.read`.
7. **Admin UK GDPR SAR Redaction UI & Statutory Retention Purge Console ([`src/GdprSarPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/GdprSarPanel.tsx))**:
   - Renders the integrated Admin SAR Redaction & Retention Purge panel (`data-testid="sar-redaction-panel"`, Sections 5C, 7B & 9.3) exclusively when the active session holds `ADMIN`/`DPO` role or `dal.staff.write:admin`.
8. **Admin-Exported PII-Scrubbed Plugin Diagnostic Bundle Console ([`src/AdminDiagnosticsPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/AdminDiagnosticsPanel.tsx))**:
   - Renders the Day-2 Operations diagnostic bundle export panel (`data-testid="admin-diagnostics-panel"`, Section 8 Gap 1, Section 9.3 & Section 10.3) with the `"Download Plugin Diagnostic Bundle"` control (`data-testid="download-plugin-diagnostic-bundle-btn"`) exclusively when the active session holds `ADMIN`/`DPO` role or `dal.staff.write:admin`.
9. **Global Search & Discovery — Landing Page Top-Half Search + Full-Page Search View (`/search`) + Command Palette (`Ctrl+K`) ([`src/components/GlobalSearchAndCommandPalette.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/GlobalSearchAndCommandPalette.tsx))**:
   - Renders the **Landing Page Top-Half Search** (`data-testid="landing-page-search-panel"`) on the Home Dashboard, the **Full-Page Search View** (`data-testid="host-search-view"`) at `/search` when the sidebar Search button is clicked, and the **Global Command Palette (`Ctrl+K`)** (`data-testid="command-palette-modal"`), indexing permitted `views[]` (omitting parameterized routes when the required entity context ID is absent) and `widgets[]` (with `keywords: string[]` synonym/verb matching and an inline `"Add to Dashboard"` action) alongside caller-scoped `pupils` and `groups` (`GET /api/system/search` with `AbortController` cancellation).
10. **Monochrome Lucide Icon Theme Contract & Modal Conventions ([`src/components/MonochromeLucideIcon.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/MonochromeLucideIcon.tsx))**:
   - **Strict Monochrome Lucide Icons (`stroke="currentColor"`, `fill="none"`, Zero Emojis)**: Every icon across the Host UI Shell (`HostSidebar`, `GlobalSearchAndCommandPalette`, `DashboardWidgetGridPanel`, `SafeguardingVaultPanel`, `GdprSarPanel`, `AdminDiagnosticsPanel`, and `App.tsx`) MUST render via [`MonochromeLucideIcon.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/MonochromeLucideIcon.tsx) (`lucide-react`, `data-lucide-icon="<name>"`, `stroke="currentColor"`, `fill="none"`) so icons automatically inherit `--mis-*` Light and WCAG AAA High-Contrast theme colors with zero emojis or unicode star/pin glyphs.
   - **Conventional Close Button (`x` Icon)**: All modal and dialog close buttons (such as `data-testid="command-palette-close-btn"` in [`GlobalSearchAndCommandPalette.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/GlobalSearchAndCommandPalette.tsx)) MUST use a conventional icon-only close button rendering `<MonochromeLucideIcon name="x" size={14} />` with `aria-label="Close"` (never text labels like `"Esc"` or `"Close"`).
