# React Host UI Shell (`ui`)

This directory contains the Vite + React Single-Page Application (SPA) compiled into [`internal/host/ui_dist`](file:///home/kieren/Documents/code/optimis/internal/host/server.go#L18-L31) and embedded into the Go Host binary via `embed.FS`.

## Architectural Responsibilities

1. **Default School MIS Dashboard Layout & `--mis-*` Theme Engine ([`src/App.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/App.tsx), [`src/components/HostSidebar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostSidebar.tsx), [`src/components/HostTopbar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostTopbar.tsx), [`src/views/DashboardSummaryStrip.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/views/DashboardSummaryStrip.tsx))**:
   - Renders the default UK All-Through School MIS workspace chrome: Left Navigation Sidebar (`data-testid="host-sidebar"` with school identity `data-testid="host-school-name"`, academic cycle badge, plugin navigation links, and `data-testid="active-entity-context-pill"`), Top Workspace Header (`data-testid="host-topbar"` with `data-testid="active-theme-mode-indicator"`, `data-testid="theme-mode-toggle-btn"`, and `data-testid="deep-link-navigation-status"`), and the Responsive Default Dashboard Grid (`data-testid="host-dashboard-grid"` & `data-testid="dashboard-summary-strip"`).
   - Fetches school branding, `--mis-*` theme catalogs (`light` & `high-contrast`), active plugin & widget descriptors, and entity link handler mappings from `GET /api/system/ui-config` ([`src/views/useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts)), waiting to mount plugin and widget `<iframe sandbox="allow-scripts">` instances until active installed plugins are resolved so uninstalled plugins never trigger 404 asset requests.
   - Applies `--mis-*` CSS Custom Properties and `data-mis-theme` onto `document.documentElement` (`:root`) and propagates live theme switches into all mounted child plugin and widget iframes without reloading.
2. **Cached Keep-Alive LRU Pool & Strict Opaque `/p/<plugid>` URL Routing (Section 9A, [`src/views/KeepAlivePluginWorkspace.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/views/KeepAlivePluginWorkspace.tsx), [`src/views/useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts), [`src/components/routeUtils.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/routeUtils.ts))**:
   - Keeps the last $N = 5$ (`MAX_KEEP_ALIVE_POOL_SIZE`) visited full-page plugin `<iframe sandbox="allow-scripts">` instances mounted inside `data-testid="keep-alive-lru-pool"` (`display: none` when inactive, `display: block` when active, `src="/p/<plugid>/ui/index.html"`) in stable DOM insertion order so tab switches never reload iframe state, and evicts the Least-Recently-Used (`lruPluginOrder[0]`) iframe when a 6th distinct plugin is visited.
   - Synchronizes every plugin view and its entity/tab state with the browser URL (`/p/<plugid>/<subpath>?<query>`) and validates direct browser navigation against `plugin.views[]` to render `data-testid="host-route-error-banner"` on undeclared paths, undeclared query parameters, or legacy `/plugins/*` URLs.
3. **Editable $N \times M$ Mini-Iframe Widget Grid (Section 9B, [`src/DashboardWidgetGridPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/DashboardWidgetGridPanel.tsx))**:
   - Renders mini-iframe widgets declared in `manifest.json` (`widgets: [{ id, title, entry }]`, served at `/p/<plugid>/ui/widget.html`) inside a responsive $N \times M$ CSS grid (`data-testid="dashboard-widget-grid"`).
   - Provides **Dashboard Edit Mode** (`data-testid="dashboard-edit-mode-toggle-btn"`) allowing staff to place widgets from the manifest catalog (`data-testid="dashboard-widget-catalog"`), resize column and row spans (`colSpan` $\times$ `rowSpan`), and remove widgets.
4. **Source-Aware Sandboxed `<iframe sandbox="allow-scripts">` RPC, Route Sync & Deep-Link Coordinator ([`src/components/useHostIframeBridge.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/useHostIframeBridge.ts), [`src/components/iframeMessageHandlers.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/iframeMessageHandlers.ts))**:
   - Maps `event.source` across all mounted Keep-Alive plugin iframes and mini-iframe widgets back to the owning opaque `plug_id`.
   - Responds to `mis:ready` with `mis:init` containing `theme_mode`, `theme_tokens` (`--mis-*`), contextual route/entity parameters, `route` (`{ path, params, query }`), and caller-scoped `permitted_methods`.
   - Intercepts `mis:route:state` from child plugin iframes, validates the target path and query against `plugin.views[]`, updates `window.history.pushState`/`replaceState` to `/p/<plugid><path>?<query>`, and posts `mis:route:changed` back to the iframe.
   - Intercepts `mis:link:navigate` emitted by `[data-mis-link]` anchors inside any plugin or widget iframe (Section 9C), resolves the target plugin's opaque `plug_id` (`data-mis-plugin="self"` or `entity_link_handlers`), builds a clean target route (`/student/:pupil_id`, `/group/:group_id`, `/staff/:staff_id`), updates the browser URL to `/p/<targetPlugId>/...`, wakes the target plugin in the Keep-Alive LRU pool, and broadcasts `mis:init` and `mis:route:changed`.
   - Intercepts `mis:rpc:request` (`{ request_id, method, args }`), forwards authenticated requests to `POST /api/p/:plug_id/rpc/:method`, and posts `mis:rpc:response` back to the originating `event.source` window.
5. **In-UI Topbar Persona Switcher (Section 8A, [`src/components/HostTopbar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostTopbar.tsx), [`src/views/useHostAdminAndDslState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostAdminAndDslState.ts))**:
   - Queries `GET /api/auth/personas` and `GET /api/auth/session` on mount. When `ENABLE_DEV_PERSONA_SWITCHER=true`, renders the interactive Topbar Persona Switcher (`data-testid="persona-switcher-container"`, `data-testid="persona-switcher-select"`, and `data-testid="active-persona-badge"`).
   - Selecting a persona (`Teacher`, `HoD`, `DSL`, `Admin/DPO`) dispatches `POST /api/auth/persona`, refreshes `GET /api/system/ui-config` to update sidebar plugins (`data-testid="nav-item-plugin-methods-count-<id>"`), toggles the DSL Safeguarding Vault and Admin/DPO SAR Redaction consoles live, and broadcasts updated `mis:init` payloads to all mounted plugin and widget iframes.
6. **DSL Safeguarding Vault & OAuth Cloud Key Unlock Panel ([`src/SafeguardingVaultPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/SafeguardingVaultPanel.tsx))**:
   - Renders the Host-level DSL Safeguarding Vault (`data-testid="dsl-safeguarding-vault-panel"`) exclusively when the active session holds `dal.safeguarding.read`.
7. **Admin UK GDPR SAR Redaction UI & Statutory Retention Purge Console ([`src/GdprSarPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/GdprSarPanel.tsx))**:
   - Renders the integrated Admin SAR Redaction & Retention Purge panel (`data-testid="sar-redaction-panel"`, Sections 5C, 7B & 9.3) exclusively when the active session holds `ADMIN`/`DPO` role or `dal.staff.write:admin`.
8. **Admin-Exported PII-Scrubbed Plugin Diagnostic Bundle Console ([`src/AdminDiagnosticsPanel.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/AdminDiagnosticsPanel.tsx))**:
   - Renders the Day-2 Operations diagnostic bundle export panel (`data-testid="admin-diagnostics-panel"`, Section 8 Gap 1, Section 9.3 & Section 10.3) with the `"Download Plugin Diagnostic Bundle"` control (`data-testid="download-plugin-diagnostic-bundle-btn"`) exclusively when the active session holds `ADMIN`/`DPO` role or `dal.staff.write:admin`.
