# Host UI Shell Views & State Hooks (`ui/src/views`)

This folder contains the primary workspace views and state hooks for the Optimis Host UI Shell.

## Key Files

* [`DashboardSummaryStrip.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/views/DashboardSummaryStrip.tsx): Renders the route validation error banner (`data-testid="host-route-error-banner"`) when a route error occurs.
* [`KeepAlivePluginWorkspace.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/views/KeepAlivePluginWorkspace.tsx): Renders the Section 9A Cached Keep-Alive LRU Plugin Workspace Pool (`data-testid="dashboard-workspace-panel"` and `data-testid="keep-alive-lru-pool"`), hiding the outer workspace card when `isVisible` is false (`hostViewMode !== 'plugin'`) or `activePluginId === ''` while keeping up to $N = 5$ (`MAX_KEEP_ALIVE_POOL_SIZE`) sandboxed `<iframe sandbox="allow-scripts">` instances mounted (`display: block` when active and `isVisible`, `display: none` otherwise), sizing active full-page plugin iframes with `minHeight: 'calc(100vh - 96px)'` and dynamic `pluginIframeHeights` reported via `mis:resize` so full-page plugin views never clip vertically.
* [`useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts): React hook managing school branding & `--mis-*` theme state (`GET /api/system/ui-config`), per-persona `pinnedRecents` (`POST /api/system/pinned-recents`), Narrow Icon Rail right-hand pane view mode (`hostViewMode: 'home' | 'search' | 'settings' | 'plugin'`, `handleNavigateHome`, `handleNavigateSearch`, `handleNavigateSettings`), Keep-Alive LRU Pool ordering and eviction (`activatePluginInKeepAlivePool`), opaque `/p/<plugid>` browser history synchronization (`syncBrowserRouteUrl`), and Personal Home Dashboard 2D Coordinate Grid persistence handlers (`dashboardColumnCount`, `handlePlaceWidget`, `handleRemoveWidget`, `handleMoveWidgetUp`, `handleMoveWidgetDown`, `handleMoveWidgetLeft`, `handleMoveWidgetRight`, `handleAddDashboardColumn`, `handleRemoveDashboardColumn`).
* [`useHostAdminAndDslState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostAdminAndDslState.ts): React hook managing caller session resolution (`GET /api/auth/session` and `mis:init` broadcast to mounted iframes), Section 5B DSL Safeguarding Vault envelope loading & OAuth Cloud Key decryption (`/api/safeguarding/*`), Section 5C Admin/DPO UK GDPR SAR Redaction & Retention Purge (`/api/admin/gdpr/*`), and Section 8 Gap 1 Admin PII-Scrubbed Diagnostic Bundle export (`/api/admin/diagnostics/bundle`).
