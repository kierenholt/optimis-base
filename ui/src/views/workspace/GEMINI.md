# Workspace State Sub-Hooks (`ui/src/views/workspace`)

This directory contains modular React sub-hooks and pure calculation helpers composed by [`useHostWorkspaceState.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/useHostWorkspaceState.ts) to manage the Optimis Host UI Shell workspace.

## Files & Sub-Hooks

* [`dashboardLayoutHelpers.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/dashboardLayoutHelpers.ts): Pure 2D grid footprint, slot collision checking (`is2DFootprintFree`), preset dimension normalization (`normalizePresetDim`), and mapping from resolved backend layout slots to `PlacedDashboardWidget` objects (`mapResolvedSlotsToPlacedWidgets`).
* [`useWorkspaceEntityContext.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/useWorkspaceEntityContext.ts): Manages active deep-linking entity context (`activePupilId`, `activeGroupId`, `activeStaffId`, `activeCaller`, `activeEntityContext`, and `deepLinkNavigationStatus`) alongside parsed initial URL route parameters (`initialSecondPupilId`, `initialOtherGroupId`, `initialAbsentStaffId`, `initialCoverStaffId`, `initialSlotId`, `initialReferenceDate`, `initialAcademicYearId`).
* [`useWorkspaceThemeAndBranding.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/useWorkspaceThemeAndBranding.ts): Manages `--mis-*` theme mode (`light` vs `high-contrast`), base font size (`small`, `medium`, `large`), theme token catalogs, school branding (`schoolName`, `schoolURN`, `configuredAcademicYear`), root DOM CSS variable injection via `applyHostThemeToRoot`, and user settings persistence to `PUT /api/system/user-settings`.
* [`useWorkspaceNavigation.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/useWorkspaceNavigation.ts): Manages opaque `/p/<plugid>/...` routing, right-hand view modes (`home`, `search`, `settings`, `plugin`), Section 9A Cached Keep-Alive LRU Pool ($N = 5$ max mounted plugin iframes, `lruPluginOrder`, `mountedPluginIds`, `activatePluginInKeepAlivePool`), browser history synchronization via `syncBrowserRouteUrl`, and route validation error tracking (`routeError`).
* [`useWorkspacePinnedRecents.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/useWorkspacePinnedRecents.ts): Manages pinned routes and recents (`pinnedRecents`), handling `POST /api/system/pinned-recents` operations (`handlePinOrUnpinRoute`, `handleUnpinRoute`) and pinned route selection (`handleSelectPinnedRoute`).
* [`useWorkspaceDashboardLayout.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/useWorkspaceDashboardLayout.ts): Manages the Personal Home Dashboard 2D coordinate grid (Section 9B), edit mode toggle (`isDashboardEditMode`), placed mini-iframe widgets (`placedWidgets`), column count (2 to 8 columns, `dashboardColumnCount`), layout persistence (`PUT /api/dashboard/layout`), widget placement (`handlePlaceWidget`), directional movement (`handleMoveWidgetUp`, `handleMoveWidgetDown`, `handleMoveWidgetLeft`, `handleMoveWidgetRight`), column adjustments (`handleAddDashboardColumn`, `handleRemoveDashboardColumn`), and role-default templates (`handleSaveRoleDefaultLayout`, `handleAppendWidgetToRoleDefault`).
* [`useWorkspaceInstalledPlugins.ts`](file:///home/kieren/Documents/code/optimis/ui/src/views/workspace/useWorkspaceInstalledPlugins.ts): Manages installed plugin list (`installedPlugins`), available widget descriptors (`availableWidgets`), dynamic entity link handlers (`entityLinkHandlers`), plugin validation against active routes (`applyInstalledPluginsState`), and full workspace bootstrapping via `GET /api/system/ui-config` & `GET /api/dashboard/layout` (`refreshWorkspaceForStaff`).
