# Personal Home Dashboard Grid Components (`ui/src/components/dashboard`)

This folder contains the modular subcomponents and layout constants powering the Section 9B Personal Home Dashboard 2D Coordinate Grid.

## Architecture & Layout Model

The Personal Home Dashboard renders a 2D coordinate grid with fixed-size cells (`300px` column width × `180px` row height) and 2 to 8 columns (default 4). In View Mode, widgets render as interactive sandboxed iframes (`sandbox="allow-scripts"`). In Edit Mode, widgets display directional movement overlays (`Up`, `Down`, `Left`, `Right`, `Delete`), empty cells render as dotted drop targets (`data-testid="dashboard-empty-grid-cell-${col}-${row}"`), and the **Widget Picker Modal** allows users to discover, filter, preview, and place widgets.

## Key Files

* [`dashboardConstants.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/dashboardConstants.ts): Layout constants defining fixed grid geometry: `FIXED_COLUMN_WIDTH_PX = 300`, `FIXED_ROW_HEIGHT_PX = 180`, `MIN_COLUMNS = 2`, and `MAX_COLUMNS = 8`.
* [`WidgetFootprintDiagram.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/WidgetFootprintDiagram.tsx): Visual 2×2 footprint indicator component rendering active filled vs muted cells (`data-footprint-width`, `data-footprint-height`), used in size filter buttons, gallery cards, split list items, and split preview headers.
* [`DashboardGridHeader.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/DashboardGridHeader.tsx): Header control bar rendering the "Home Dashboard Widgets" title, save status badge (`data-testid="dashboard-layout-save-status"`), `+ Add Widget` button, `Cancel Placement` button, column controls (`- Remove Column`, column count badge, `+ Add Column`), and `Finish Editing Grid` / `Edit Dashboard Grid` toggle.
* [`PlacedWidgetCard.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/PlacedWidgetCard.tsx): Placed widget card bounded to explicit CSS Grid coordinates (`gridColumn: col / span W`, `gridRow: row / span H`). Renders sandboxed `<iframe sandbox="allow-scripts">` when permitted, permission error cards (`data-testid="widget-permission-error-card-<id>"`) when unpermitted, and directional shift overlays (`widget-edit-overlay-<id>`) with Up/Down/Left/Right/Delete controls in Edit Mode.
* [`DashboardEmptyCell.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/DashboardEmptyCell.tsx): Dotted 1×1 grid cell drop target (`data-testid="dashboard-empty-grid-cell-${col}-${row}"`) handling mouse enter/move to position the ghost preview and click to confirm placement.
* [`DashboardPlacementPreview.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/DashboardPlacementPreview.tsx): Ghost preview box (`data-testid="dashboard-widget-placement-preview"`) displaying the pending widget at candidate (col, row) coordinates prior to placement confirmation.
* [`WidgetPickerModal.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/WidgetPickerModal.tsx): Centered dialog modal (`data-testid="dashboard-widget-picker-modal"`) managing search filtering (`widget-picker-search-input`), size filter pills (`widget-picker-size-filter-*`), plugin filtering (`widget-picker-plugin-filter`), `Hide already placed` toggle (`widget-picker-hide-placed-toggle`), and switching between Gallery View and Split Preview.
* [`WidgetPickerGalleryView.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/WidgetPickerGalleryView.tsx): Responsive multi-column grid (`data-testid="widget-picker-gallery-view"`) of widget cards displaying title, monochrome Lucide icon, footprint diagram, plugin name, description, and `+ Place` action button.
* [`WidgetPickerSplitView.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/WidgetPickerSplitView.tsx): Two-column layout (`data-testid="widget-picker-split-view"`) containing a scrollable widget listbox (`widget-picker-split-list`) on the left and a detailed preview pane (`widget-picker-split-preview`) with live sandboxed preview iframe (`widget-picker-live-preview-iframe`) on the right.
* [`index.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/dashboard/index.ts): Barrel export aggregating all dashboard components and constants.
