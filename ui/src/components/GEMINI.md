# Host UI Shell Components & Bridge (`ui/src/components`)

This folder contains the global navigation chrome, route validation utilities, and `window.postMessage` iframe RPC/route bridge for the Optimis Host UI Shell.

## Key Files

* [`GlobalSearchAndCommandPalette.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/GlobalSearchAndCommandPalette.tsx): Implements `LandingPageTopHalfSearch` (`data-testid="landing-page-search-panel"`) and `GlobalCommandPaletteModal` (`data-testid="command-palette-modal"`), indexing permitted `views[]` (with `data-permitted-count`, `data-permitted-methods`, and inline pin buttons `data-testid="search-pin-view-btn-<plugId>-<viewId>"`) and `widgets[]` (keyed by composite `plug_id:widget_id`, with `keywords: string[]` synonym/verb matching and inline `"Add to Dashboard"` buttons) and caller-scoped `pupils` & `groups` (`GET /api/system/search`).
* [`HostSidebar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostSidebar.tsx): Renders the Section 9.5 Left Sidebar **Narrow Icon Rail** (`data-testid="host-sidebar"`, `data-rail-mode="narrow-icon-rail"`), replacing the full installed-plugin list with strictly **Home** (`data-testid="nav-rail-home"`), **Global Search (🔍)** (`data-testid="nav-rail-search"`), **Pinned Recents** (`data-testid="nav-rail-pinned-recents"`, rendering manually pinned routes `data-testid="pinned-recent-item-<idx>"` and unpin controls `data-testid="unpin-recent-btn-<idx>"`), **Settings** (`data-testid="nav-rail-settings"`), and **Logout** (`data-testid="nav-rail-logout"`), plus compact school identity (`data-testid="host-school-name"`) and Active Entity Context (`data-testid="active-entity-context-pill"`) badges.
* [`HostTopbar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostTopbar.tsx): Renders the Top Workspace Header (`data-testid="host-topbar"`), Global Command Palette trigger button (`data-testid="command-palette-trigger-btn"`), deep-link routing status (`data-testid="deep-link-navigation-status"`), current browser route (`data-testid="host-active-route-url"`), active plugin badge (`data-testid="topbar-active-plugin-badge"` with `data-testid="topbar-active-plugin-methods-count"`) & manual **"Pin View"** button (`data-testid="topbar-pin-view-btn"`), the Section 8A Dev Persona Switcher (`data-testid="persona-switcher-container"`, `data-testid="persona-switcher-select"`, `data-testid="active-persona-badge"`), and the `--mis-*` Light / WCAG AAA High-Contrast theme switcher (`data-testid="theme-mode-toggle-btn"`).
* [`routeUtils.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/routeUtils.ts): Browser URL parser (`parseBrowserRoute`), manifest `views[]` path and query parameter validator (`validatePluginViewRoute`), `HOST_ALLOWED_QUERY_KEYS`, and `checkCallerAdminOrDpo` RBAC helper.
* [`iframeMessageHandlers.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/iframeMessageHandlers.ts): Constructs `mis:init` payloads (`createInitPayload`) and processes `mis:route:state` (`handleRouteStateMessage`) and `mis:link:navigate` (`handleLinkNavigateMessage`) cross-plugin deep-link messages.
* [`useHostIframeBridge.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/useHostIframeBridge.ts): React hook managing `pluginIframeRefs` (keyed by `plug_id`) and `widgetIframeRefs` (keyed by composite `plug_id:widget_id`), broadcasting `mis:init` on mount/state changes, synchronizing browser `popstate` events, and handling `window.postMessage` (`mis:ready`, `mis:route:state`, `mis:link:navigate`, and `mis:rpc:request` with `X-MIS-Staff-ID` propagation and `mis:plugin:invalidated` broadcast on `mutates: true` calls).
