# Host UI Shell Components & Bridge (`ui/src/components`)

This folder contains the global navigation chrome, route validation utilities, and `window.postMessage` iframe RPC/route bridge for the Optimis Host UI Shell.

## Key Files

* [`GlobalSearchAndCommandPalette.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/GlobalSearchAndCommandPalette.tsx): Implements `LandingPageTopHalfSearch` (`data-testid="landing-page-search-panel"`, including the **"Full list"** button `data-testid="landing-open-command-palette-btn"`, record-type filter tabs `data-testid="landing-search-filter-all"`, `landing-search-filter-plugins`, `landing-search-filter-widgets`, `landing-search-filter-pupils`, `landing-search-filter-groups`, and inline view pin buttons `data-testid="landing-search-pin-view-btn-<plugId>-<viewId>"`), `HostFullPageSearchView` (`data-testid="host-search-view"`, rendered as the full-page right-hand pane view at `/search` when the sidebar Search button is clicked, with `host-search-input`, `host-search-tab-*`, `host-search-results`, `host-search-result-view-*`, `host-search-result-widget-*`, `host-search-result-pupil-*`, `host-search-result-group-*`, `host-search-pin-view-btn-*`, `host-search-add-widget-btn-*`), and `GlobalCommandPaletteModal` (`data-testid="command-palette-modal"`, triggered via `Ctrl+K` or "Full list" button, with a conventional `<MonochromeLucideIcon name="x" size={14} />` close button `data-testid="command-palette-close-btn"` and category tabs `data-testid="command-palette-tab-all"`, `command-palette-tab-plugins`, `command-palette-tab-widgets`, `command-palette-tab-pupils`, and `command-palette-tab-groups`), indexing permitted `views[]` (omitting parameterized routes when the required entity context ID is absent, and exposing `data-permitted-count`, `data-permitted-methods`, and inline pin buttons) and `widgets[]` (keyed by composite `plug_id:widget_id`, with `keywords: string[]` synonym/verb matching and inline `"Add to Dashboard"` buttons) and caller-scoped `pupils` & `groups` (`GET /api/system/search` with `AbortController` cancellation).
* [`MonochromeLucideIcon.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/MonochromeLucideIcon.tsx): Renders monochrome (`stroke="currentColor" fill="none"`, `data-lucide-icon="<name>"`) Lucide icons (`lucide-react`) across the Host UI Shell (`house`, `search`, `pin`, `settings`, `log-out`, `x`, `arrow-up`, `arrow-down`, `plus`, `check`, `layout-grid`, `shield-alert`, `key-round`, `lock-open`, `file-search`, `trash-2`, `activity`, `download`, `user`, `users`, `chevron-right`, and all plugin manifest icons), ensuring zero emojis and automatic `--mis-*` Light / WCAG AAA High-Contrast `currentColor` inheritance.
* [`HostSidebar.tsx`](file:///home/kieren/Documents/code/optimis/ui/src/components/HostSidebar.tsx): Renders the Section 9.5 Left Sidebar **Narrow Icon Rail** (`data-testid="host-sidebar"`, `data-rail-mode="narrow-icon-rail"`, sticky and bounded to the viewport via `height: calc(100vh / var(--mis-font-scale, 1))` so it never exceeds `window.innerHeight` at `large` or `extra-large` font sizes), replacing the full installed-plugin list with strictly **Home** (`data-testid="nav-rail-home"`, `<MonochromeLucideIcon name="house" />`, setting `aria-current="page"` when `hostViewMode === 'home'`), **Global Search** (`data-testid="nav-rail-search"`, `<MonochromeLucideIcon name="search" />`, navigating to `/search` and setting `aria-current="page"` when `hostViewMode === 'search'`), **Pinned Recents** (`data-testid="nav-rail-pinned-recents"`, rendering the manual **"Pin Current View"** button `data-testid="topbar-pin-view-btn"` with `<MonochromeLucideIcon name="pin" />` when `hostViewMode === 'plugin'` and an active plugin view is open, manually pinned routes `data-testid="pinned-recent-item-<idx>"` with each plugin's declared monochrome Lucide icon, and unpin controls `data-testid="unpin-recent-btn-<idx>"` with `<MonochromeLucideIcon name="x" />`), **Settings** (`data-testid="nav-rail-settings"`, `<MonochromeLucideIcon name="settings" />`, navigating to `/settings` and setting `aria-current="page"` when `hostViewMode === 'settings'`), and **Logout** (`data-testid="nav-rail-logout"`, `<MonochromeLucideIcon name="log-out" />`), plus the compact school identity (`data-testid="host-school-name"`) badge.
* [`routeUtils.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/routeUtils.ts): Browser URL parser (`parseBrowserRoute` resolving `HostViewMode: 'home' | 'search' | 'settings' | 'plugin'`), manifest `views[]` path and query parameter validator (`validatePluginViewRoute`), `HOST_ALLOWED_QUERY_KEYS`, and `checkCallerAdminOrDpo` RBAC helper.
* [`iframeMessageHandlers.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/iframeMessageHandlers.ts): Constructs `mis:init` payloads (`createInitPayload`) and processes `mis:route:state` (`handleRouteStateMessage`) and `mis:link:navigate` (`handleLinkNavigateMessage`) cross-plugin deep-link messages.
* [`useHostIframeBridge.ts`](file:///home/kieren/Documents/code/optimis/ui/src/components/useHostIframeBridge.ts): React hook managing `pluginIframeRefs` (keyed by `plug_id`) and `widgetIframeRefs` (keyed by composite `plug_id:widget_id`), broadcasting `mis:init` on mount/state changes, synchronizing browser `popstate` events, and handling `window.postMessage` (`mis:ready`, `mis:route:state`, `mis:link:navigate`, and `mis:rpc:request` with `X-MIS-Staff-ID` propagation and `mis:plugin:invalidated` broadcast on `mutates: true` calls).
