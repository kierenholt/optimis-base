# Core Data Access Layer & Identity/Persona Resolution (`internal/dal`)

This package implements the **Optimis Core Data Access Layer (`CoreDAL`)** over `core.db` and attached `plugin_<alias>.db` SQLite databases (Sections 2, 3, 5, 7, and 9.3 of the Architecture Blueprint).

---

## 1. Architectural Invariants Enforced by `CoreDAL`

1. **Separated SQLite WAL Connection Pools ([`dal.go`](file:///home/kieren/Documents/code/optimis/internal/dal/dal.go))**:
   * `WriteDB` (`MaxOpenConns(1)`): Serializes all database writes (`BEGIN IMMEDIATE` / transactions) without `SQLITE_BUSY` contention.
   * `ReadDB` (`MaxOpenConns(NumCPU)`): Serves concurrent WAL reads across CPU cores, using a driver-level [`ConnectHook`](file:///home/kieren/Documents/code/optimis/internal/dal/dal.go#L30) so dynamically attached `plugin_<alias>.db` files and `PRAGMA <alias>.max_page_count` limits stay synchronized across every pooled connection.
2. **Database-Backed Staff Persona, RBAC Scope & `__system_config` Resolution ([`persona_auth.go`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go) & [`system_config_sso.go`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go))**:
   * [`ListActiveStaffPersonas`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go) and [`ResolveStaffPersonaByID`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go) resolve staff identities against `staff`, `persons`, temporal `person_roles`, and `roles.default_scopes_json`.
   * **Fail-Fast Guards**: Rejects missing `staff_id`, non-`ACTIVE` `persons.status`, staff with a non-empty `termination_date`, or staff with zero active roles.
   * [`ListSystemConfigEntries`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go), [`GetSystemConfigEntry`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go), [`GetSystemConfigValue`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go), [`SetSystemConfigValue`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go), [`ValidateAndLoadSSOConfig`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go), and [`RepairSSOConfig`](file:///home/kieren/Documents/code/optimis/internal/dal/system_config_sso.go) read, validate, and atomically repair runtime configuration keys (`sso_oidc_issuer_url`, `sso_oidc_client_id`, `sso_provider`, `sso_redirect_uri`, etc.) in `__system_config` with zero silent fallbacks.
3. **Temporal (`:own_groups` vs `:all`), Statutory Session & Safeguarding Invariants**:
   * **Row-Level Temporal Filtering ([`domains.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains.go), [`domains_pupils.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_pupils.go), [`domains_pupils_enrolment_fsm.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_pupils_enrolment_fsm.go), [`domains_pupils_statutory_pastoral.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_pupils_statutory_pastoral.go), & [`domains_sen_medical.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_sen_medical.go))**: When a query runs with `ScopeOwnGroups`, SQL results are restricted to groups and pupils where the calling `staff_id` holds an active `group_staff_assignments` row (`effective_from <= reference_date AND (effective_to IS NULL OR effective_to >= reference_date)`).
   * **Groups, Timetable & Statutory Attendance (`AM` / `PM`) ([`domains_groups.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_groups.go), [`domains_timetable.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_timetable.go), & [`domains_attendance.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_attendance.go))**: [`UpsertSessionAttendanceBatchScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_attendance.go) validates statutory `AM`/`PM` sessions and writes both `attendance_session_marks` and `attendance_session_register_submissions` audit rows atomically on `WriteDB`.
   * **Guardian PR & Court-Order Blocks ([`domains_guardians.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians.go), [`domains_guardians_contacts.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_contacts.go), & [`domains_guardians_households.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_households.go))**: [`ListGuardiansForPupilScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians.go) strictly excludes any guardian with `court_order_restricted = 1`, enforces `has_parental_responsibility = 1` when requested, and redacts address fields whenever `households.is_confidential_address = 1`. [`UpsertGuardianContactScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_contacts.go) enforces relationship contact defaults, court-order restriction overrides, and household/person persistence. [`ListSiblingsForPupilScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_households.go) and [`ListHouseholdsScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_households.go) discover sibling graphs and household directories with confidential address redaction.
   * **Safeguarding Envelope Encryption ([`domains_safeguarding.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_safeguarding.go))**: [`CreateSafeguardingPostboxNote`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_safeguarding.go) encrypts notes using per-record AES-256-GCM DEKs wrapped under `HOST_KMS_KEY_HANDLE` and records an immutable `CREATE_POSTBOX` audit entry. [`ListSafeguardingNoteEnvelopesDSL`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_safeguarding.go) returns encrypted envelope metadata strictly to `is_dsl = 1` staff without decrypting ciphertext. [`ReadSafeguardingNoteDSL`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_safeguarding.go) verifies `staff.is_dsl = 1` and a valid signed short-lived DSL Cloud Key token ([`IssueDSLCloudKeyToken`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_safeguarding.go)) before unwrapping the DEK, decrypting the payload, and recording an append-only `DSL_DECRYPT_VIEW` audit log entry.
   * **Statutory DfE School Census Rollup ([`domains_census.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_census.go))**: [`GetStatutoryCensusRollup`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_census.go) enforces `ScopeAll` (`dal.census.read:all`), resolves on-roll pupils as of `census_date` (`pupil_year_enrolments.effective_from <= census_date AND (effective_to IS NULL OR effective_to >= census_date)` and `enrolment_status IN ('C','M','S','F','O')`), strictly excludes off-roll pupils whose `effective_to < census_date`, aggregates effective-dated SEN (`E`/`K`/`N` + primary need), FSM (`pupil_fsm_periods`), and Looked-After (`looked_after_flag` / `post_looked_after_code`) statuses, and computes statutory `AM`/`PM` attendance session marks (`possible_sessions`, `present_sessions`, `authorised_absence_sessions`, `unauthorised_absence_sessions`) within `[attendance_start_date, attendance_end_date]`.
4. **UK GDPR Subject Access Request (SAR) Export & Statutory Retention Purge ([`gdpr.go`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go))**:
   * [`ExportCorePupilSAR`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L19): Exports structured `[]SARSection` tables (`title`, `records`, `redactable_fields`) across Core domains.
   * [`CheckPupilRetentionPurgeEligible`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L297) & [`PurgeCorePupilData`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L342): Enforces KCSIE safeguarding retention locks (`KCSIE_RETENTION_LOCK`) before atomically purging all pupil records across `core.db`.
5. **Standard Core Domain Event Catalog & Post-Commit Dispatch ([`events.go`](file:///home/kieren/Documents/code/optimis/internal/dal/events.go))**:
   * Defines the canonical Core Event Catalog (`core.pupil.enrolled`, `core.group.membership_changed`, `core.attendance.session_recorded`, `core.safeguarding.postbox_created`, and `core.gdpr.pupil_purged`) and dispatches events strictly **after** `WriteDB` transactions commit.
