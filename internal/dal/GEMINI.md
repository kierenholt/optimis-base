# Core Data Access Layer & Identity/Persona Resolution (`internal/dal`)

This package implements the **Optimis Core Data Access Layer (`CoreDAL`)** over `core.db` and attached `plugin_<alias>.db` SQLite databases (Sections 2, 3, 5, 7, and 9.3 of the Architecture Blueprint).

---

## 1. Architectural Invariants Enforced by `CoreDAL`

1. **Separated SQLite WAL Connection Pools ([`dal.go`](file:///home/kieren/Documents/code/optimis/internal/dal/dal.go))**:
   * `WriteDB` (`MaxOpenConns(1)`): Serializes all database writes (`BEGIN IMMEDIATE` / transactions) without `SQLITE_BUSY` contention.
   * `ReadDB` (`MaxOpenConns(NumCPU)`): Serves concurrent WAL reads across CPU cores, using a driver-level [`ConnectHook`](file:///home/kieren/Documents/code/optimis/internal/dal/dal.go#L47) so dynamically attached `plugin_<alias>.db` files and `PRAGMA <alias>.max_page_count` limits stay synchronized across every pooled connection.
2. **Database-Backed Staff Persona, RBAC Scope & `__system_config` Resolution ([`persona_auth.go`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go))**:
   * [`ListActiveStaffPersonas`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go) and [`ResolveStaffPersonaByID`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go) resolve staff identities against `staff`, `persons`, temporal `person_roles`, and `roles.default_scopes_json`.
   * **Fail-Fast Guards**: Rejects missing `staff_id`, non-`ACTIVE` `persons.status`, staff with a non-empty `termination_date`, or staff with zero active roles.
   * [`ListSystemConfigEntries`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go), [`GetSystemConfigEntry`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go), [`GetSystemConfigValue`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go), [`SetSystemConfigValue`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go), [`ValidateAndLoadSSOConfig`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go), and [`RepairSSOConfig`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go) read, validate, and atomically repair runtime configuration keys (`sso_oidc_issuer_url`, `sso_oidc_client_id`, `sso_provider`, `sso_redirect_uri`, etc.) in `__system_config` with zero silent fallbacks.
3. **Temporal (`:own_groups` vs `:all`), Statutory Session & Safeguarding Invariants**:
   * **Row-Level Temporal Filtering ([`domains.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains.go) & [`domains_pupils.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_pupils.go))**: When a query runs with `ScopeOwnGroups`, SQL results are restricted to groups and pupils where the calling `staff_id` holds an active `group_staff_assignments` row (`effective_from <= reference_date AND (effective_to IS NULL OR effective_to >= reference_date)`).
   * **Groups, Timetable & Statutory Attendance (`AM` / `PM`) ([`domains_groups_attendance.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_groups_attendance.go))**: [`UpsertSessionAttendanceBatchScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_groups_attendance.go) validates statutory `AM`/`PM` sessions and writes both `attendance_session_marks` and `attendance_register_submissions` audit rows atomically on `WriteDB`.
   * **Guardian PR & Court-Order Blocks ([`domains_guardians_safeguarding.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go))**: [`ListGuardiansForPupilScoped`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go) strictly excludes any guardian with `court_order_restricted = 1`, enforces `has_parental_responsibility = 1` when requested, and redacts address fields whenever `households.is_confidential_address = 1`.
   * **Safeguarding Envelope Encryption ([`domains_guardians_safeguarding.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go))**: [`CreateSafeguardingPostboxNote`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go) encrypts notes using per-record AES-256-GCM DEKs wrapped under `HOST_KMS_KEY_HANDLE` and records an immutable `CREATE_POSTBOX` audit entry. [`ListSafeguardingNoteEnvelopesDSL`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go) returns encrypted envelope metadata strictly to `is_dsl = 1` staff without decrypting ciphertext. [`ReadSafeguardingNoteDSL`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go) verifies `staff.is_dsl = 1` and a valid signed short-lived DSL Cloud Key token ([`IssueDSLCloudKeyToken`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go)) before unwrapping the DEK, decrypting the payload, and recording an append-only `DSL_DECRYPT_VIEW` audit log entry.
   * **Statutory DfE School Census Rollup ([`domains_census.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_census.go))**: [`GetStatutoryCensusRollup`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_census.go) enforces `ScopeAll` (`dal.census.read:all`), resolves on-roll pupils as of `census_date` (`pupil_year_enrolments.effective_from <= census_date AND (effective_to IS NULL OR effective_to >= census_date)` and `enrolment_status IN ('C','M','S','F','O')`), strictly excludes off-roll pupils whose `effective_to < census_date`, aggregates effective-dated SEN (`E`/`K`/`N` + primary need), FSM (`pupil_fsm_periods`), and Looked-After (`looked_after_flag` / `post_looked_after_code`) statuses, and computes statutory `AM`/`PM` attendance session marks (`possible_sessions`, `present_sessions`, `authorised_absence_sessions`, `unauthorised_absence_sessions`) within `[attendance_start_date, attendance_end_date]`.
4. **UK GDPR Subject Access Request (SAR) Export & Statutory Retention Purge ([`gdpr.go`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go))**:
   * [`ExportCorePupilSAR`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L41): Exports structured `[]SARSection` tables (`title`, `records`, `redactable_fields`) across Core domains.
   * [`CheckPupilRetentionPurgeEligible`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L319) & [`PurgeCorePupilData`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L364): Enforces KCSIE safeguarding retention locks (`KCSIE_RETENTION_LOCK`) before atomically purging all pupil records across `core.db`.
5. **Standard Core Domain Event Catalog & Post-Commit Dispatch ([`events.go`](file:///home/kieren/Documents/code/optimis/internal/dal/events.go))**:
   * Defines the canonical Core Event Catalog (`core.pupil.enrolled`, `core.group.membership_changed`, `core.attendance.session_recorded`, `core.safeguarding.postbox_created`, and `core.gdpr.pupil_purged`) and dispatches events strictly **after** `WriteDB` transactions commit.

## 2. Key Files

* [`dal.go`](file:///home/kieren/Documents/code/optimis/internal/dal/dal.go): SQLite WAL pool initialization, `ConnectHook` `ATTACH`/`DETACH` synchronization, 45-table `schema/core/*.sql` bootstrap, and basic pupil seed helpers.
* [`domains.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains.go): `DALQueryScope` types, `ResolveScopeDefaults`, and `:own_groups` vs `:all` temporal assignment verification (`ensureGroupInOwnGroups`, `ensurePupilInOwnGroups`).
* [`domains_pupils.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_pupils.go): Scoped pupil profile, batch pupil profile, school-wide pupil directory, group roster, and batch SEN/Medical alert queries (`GetPupilByIDScoped`, `GetPupilsByIDsBatchScoped`, `ListAllPupilsScoped`, `ListPupilsByGroupScoped`, `ListPupilSenAndMedicalBatch`), returning both preferred (`preferred_first_name`, `preferred_last_name`) and legal (`legal_first_name`, `legal_last_name`) name fields plus `nc_year_group` and `enrolment_status`.
* [`domains_groups_attendance.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_groups_attendance.go): Scoped teaching/registration groups, active staff directory (`ListActiveStaff`, `GetStaffByID`), staff timetable slots, group pupil membership and temporal staff assignment upserts, and statutory `AM`/`PM` attendance batch & pupil summary operations (`ListGroupsScoped`, `GetStaffTimetableSlotsScoped`, `UpsertGroupPupilMembershipScoped`, `UpsertGroupStaffAssignmentScoped`, `GetGroupSessionAttendanceScoped`, `GetPupilAttendanceSummaryScoped`, `UpsertSessionAttendanceBatchScoped`).
* [`domains_guardians_safeguarding.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_guardians_safeguarding.go): Single-pupil and batch guardian court-order/confidential-address filtering (`ListGuardiansForPupilScoped`, `ListGuardiansForPupilsBatchScoped`) and AES-256-GCM envelope-encrypted DSL safeguarding vault (`CreateSafeguardingPostboxNote`, `IssueDSLCloudKeyToken`, `ReadSafeguardingNoteDSL`, `ListSafeguardingNoteEnvelopesDSL`).
* [`domains_census.go`](file:///home/kieren/Documents/code/optimis/internal/dal/domains_census.go): Statutory DfE School Census rollup query (`GetStatutoryCensusRollup`) and isolated census test fixture seeding/cleanup (`SeedCensusTestFixtures`, `DeleteCensusTestFixtures`).
* [`events.go`](file:///home/kieren/Documents/code/optimis/internal/dal/events.go): Standard Core Domain Event Catalog definitions, event subscription validation, context hop-count propagation (`WithEventHop` / `EventHopFromContext`), and post-commit hook dispatch.
* [`persona_auth.go`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go): Staff persona listing, single-staff role/scope resolution (including `dal.groups.write:all` for `HOD` and `dal.medical.read:all` for `SUPPORT` / `SchoolNurseStaffID`), `__system_config` list/get/set/delete & SSO validation/repair (`ListSystemConfigEntries`, `GetSystemConfigEntry`, `SetSystemConfigValue`, `ValidateAndLoadSSOConfig`, `RepairSSOConfig`), and isolated persona test fixture seeding/cleanup.
* [`gdpr.go`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go): Core UK GDPR SAR export section builder, KCSIE retention pre-flight check, atomic Core pupil retention purge, and isolated GDPR test fixture seeding/teardown.
* [`test_fixtures.go`](file:///home/kieren/Documents/code/optimis/internal/dal/test_fixtures.go): Milestone 1 and vertical domain scoping test fixture seeding and teardown (`SeedMilestone1Fixtures`, `DeleteMilestone1Fixtures`, including `CRITICAL` IHCP/Anaphylaxis medical condition alerts, rolling Week 1 `AM` / Week 2 `PM` `timetable_periods` & `timetable_slots`, and optional `IncludeSecondActivePupil` roster fixtures).
* [`core_schema_functional_test.go`](file:///home/kieren/Documents/code/optimis/internal/dal/core_schema_functional_test.go) & [`core_dal_domains_test.go`](file:///home/kieren/Documents/code/optimis/internal/dal/core_dal_domains_test.go): Isolated SQLite WAL unit and functional tests covering all 45 core tables and domain scoping invariants.
