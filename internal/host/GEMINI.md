# Go Host Runtime, Session/Persona Resolution & RPC Gateway (`internal/host`)

This package implements the **Optimis Go Host Container** (Sections 5, 7, 8, 9, and 10 of the Architecture Blueprint), responsible for authentication/persona session resolution, HTTP/RPC routing, capability-sandboxed `gopher-lua` execution, per-plugin SQLite lifecycle/migration management, UK GDPR SAR export & retention purge orchestration, post-commit Event Bus dispatch, and PII-scrubbed diagnostic capture.

---

## 1. Key Files & Responsibilities

* [`host.go`](file:///home/kieren/Documents/code/optimis/internal/host/host.go):
  * [`NewHost`](file:///home/kieren/Documents/code/optimis/internal/host/host.go#L118): Initializes the Host container, mounts `core.db` via [`dal.NewCoreDAL`](file:///home/kieren/Documents/code/optimis/internal/dal/dal.go#L97), and initializes the in-memory Event Bus and PII-scrubbed diagnostic ring buffer.
  * [`LoadPlugin`](file:///home/kieren/Documents/code/optimis/internal/host/host.go#L521) & [`GetLoadedPlugin`](file:///home/kieren/Documents/code/optimis/internal/host/host.go#L544): Validates `manifest.json` and `src/init.lua` from disk (failing fast if `database.alias` is declared without mandatory `gdpr_hooks.export_pupil_data` and `gdpr_hooks.purge_pupil_data`), takes file-level `.snapshot` backups of `plugin_<alias>.db`, runs pending `migrations/*.sql` inside `BEGIN IMMEDIATE` with automatic snapshot rollback on failure, and attaches the plugin database across `WriteDB` and `ReadDB`.
  * [`ExecuteRPC`](file:///home/kieren/Documents/code/optimis/internal/host/host.go#L572) & [`ExecuteWorker`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go): Enforces `PluginStateActive` (blocking `UNINSTALLED_DORMANT` plugins with `PLUGIN_DORMANT_QUARANTINE`), default-deny `manifest.json` endpoint/worker declarations, and RBAC scopes before executing inside a stripped Lua 5.1 VM (`io`, `os`, `debug`, `package`, `dofile`, `loadfile`, `require` removed).
* [`gdpr.go`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go):
  * [`SetPluginState`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go#L61) & [`UninstallPlugin`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go#L84): Manages transitions between `ACTIVE` and `UNINSTALLED_DORMANT` (Section 8 Gap 3 & Section 9.3.4), disabling endpoints/workers/UI while keeping `plugin_<alias>.db` and `gdpr_hooks` mounted for statutory compliance.
  * [`ExportPupilSAR`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go#L256) & [`FinalizePupilSAR`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go#L305): Verifies Admin/DPO authority, aggregates Core SAR sections from [`CoreDAL.ExportCorePupilSAR`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L41), and invokes `gdpr_hooks.export_pupil_data(ctx, pupil_id)` across all attached plugins (`ACTIVE` and `UNINSTALLED_DORMANT`).
  * [`PurgePupilData`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go#L333): Verifies Admin/DPO write authority, enforces pre-flight KCSIE safeguarding retention checks (`KCSIE_RETENTION_LOCK`), invokes `gdpr_hooks.purge_pupil_data(ctx, pupil_id)` across all attached plugins, and executes [`CoreDAL.PurgeCorePupilData`](file:///home/kieren/Documents/code/optimis/internal/dal/gdpr.go#L326).
  * [`RegisterGDPRRoutes`](file:///home/kieren/Documents/code/optimis/internal/host/gdpr.go#L390): Registers `POST /api/admin/gdpr/sar/export`, `POST /api/admin/gdpr/sar/finalize`, `POST /api/admin/gdpr/purge`, and `POST /api/admin/plugins/{plugin_id}/state`.
* [`persona_auth.go`](file:///home/kieren/Documents/code/optimis/internal/host/persona_auth.go):
  * **Environment Flag Gate (`ENABLE_DEV_PERSONA_SWITCHER`)**:
    * [`ConfigureAuthMode`](file:///home/kieren/Documents/code/optimis/internal/host/persona_auth.go#L72-L89) configures whether the Host operates in Dev Persona Switcher mode (`true`) or Real Federated SSO mode (`false`).
    * **Fail-Fast Real SSO Invariant**: When `ENABLE_DEV_PERSONA_SWITCHER=false`, [`loadRealSSOProvider`](file:///home/kieren/Documents/code/optimis/internal/host/persona_auth.go#L57-L70) queries `__system_config` for `sso_oidc_issuer_url` and `sso_oidc_client_id` and fails fast immediately with `REAL_SSO_NOT_CONFIGURED`.
  * **Session & Persona Resolution**:
    * [`ResolveRequestCaller`](file:///home/kieren/Documents/code/optimis/internal/host/persona_auth.go#L99-L199) resolves the [`CallerContext`](file:///home/kieren/Documents/code/optimis/internal/host/host.go#L86-L93) for every incoming request by inspecting the `SameSite=Strict; HttpOnly` `mis_session` cookie (or active dev persona selection) and querying [`CoreDAL.ResolveStaffPersonaByID`](file:///home/kieren/Documents/code/optimis/internal/dal/persona_auth.go#L200-L263) against `core.db`.
* [`safeguarding_vault.go`](file:///home/kieren/Documents/code/optimis/internal/host/safeguarding_vault.go):
  * [`RegisterSafeguardingRoutes`](file:///home/kieren/Documents/code/optimis/internal/host/safeguarding_vault.go#L22): Exposes Host-level Section 5B endpoints (`POST /api/safeguarding/postbox`, `GET /api/safeguarding/notes`, `POST /api/safeguarding/cloud-key/renew`, and `POST /api/safeguarding/notes/{note_id}/decrypt`).
* [`dal_bindings.go`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go):
  * Binds capability-scoped `ctx.dal.<domain>` Lua namespaces (`pupils`, `groups`, `attendance`, `guardians`, `safeguarding`), dynamically omitting any domain not declared in the current endpoint/worker's `manifest.json` scopes and ensuring `ctx.dal.safeguarding` is strictly write-only (`create_postbox` only).
* [`server.go`](file:///home/kieren/Documents/code/optimis/internal/host/server.go):
  * [`NewHTTPHandler`](file:///home/kieren/Documents/code/optimis/internal/host/server.go#L19): Mounts the embedded React UI (`ui_dist`), serves sandboxed plugin assets (`GET /plugins/{plugin_id}/ui/{asset_path...}`) with `Content-Security-Policy: default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; connect-src 'none';`, registers auth/persona, safeguarding vault, and GDPR routes, and dispatches `POST /api/plugins/{plugin_id}/rpc/{method}`.
