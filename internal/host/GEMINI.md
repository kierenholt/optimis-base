# Go Host Runtime, Session/Persona Resolution & RPC Gateway (`internal/host`)

This package implements the **Optimis Go Host Container** (Sections 5, 7, 8, 9, and 10 of the Architecture Blueprint), responsible for authentication/persona session resolution, HTTP/RPC routing, capability-sandboxed `gopher-lua` execution, per-plugin SQLite lifecycle/migration management, UK GDPR SAR export & retention purge orchestration, post-commit Event Bus dispatch, and PII-scrubbed diagnostic capture.

---

## 1. Subpackage Architecture

To preserve clean modular separation and prevent package bloat, domain concerns are segregated into focused subpackages:

* **[`dalbindings/`](file:///home/kieren/Documents/code/optimis/internal/host/dalbindings/GEMINI.md):** The 12 capability-scoped Core DAL Lua namespaces (`ctx.dal.academic`, `pupils`, `groups`, `staff`, `attendance`, `guardians`, `safeguarding`, `sen`, `medical`, `census`, and `dashboard`) decoupled from `Host` internals via [`dalbindings.Bind`](file:///home/kieren/Documents/code/optimis/internal/host/dalbindings/bindings.go#L31).
* **[`types/`](file:///home/kieren/Documents/code/optimis/internal/host/types/GEMINI.md):** Common manifest, caller identity, and RPC types (`Config`, `Manifest`, `LoadedPlugin`, `CallerContext`, `EndpointSpec`, `RPCResponse`, `Event`) shared across the Host runtime and subpackages with zero circular import dependencies.
* **[`tests/`](file:///home/kieren/Documents/code/optimis/internal/host/tests/GEMINI.md):** All 19 unit, integration, and sample plugin test suites segregated from production runtime code.
