# Staff Cover Manager & Supply Teacher Plugin (`plugins/staff_cover_plugin`)

This directory contains **Vertical 8 (`uk.org.optimis.ops.cover`)**, a first-party operations plugin with an attached SQLite database (`plugin_cover`) that implements teacher absence recording, affected timetable slot discovery (`ctx.dal.groups.get_staff_timetable_slots`) with available free cover staff lookup (`ctx.dal.groups.list_free_staff_for_period`), dynamic temporal cover assignment (`ctx.dal.groups.upsert_staff_assignment` with `role = "COVER_TEACHER"`) granting immediate `:own_groups` access to the supply/cover teacher for the cover date, cover revocation (`ctx.dal.groups.revoke_staff_assignment`), class roster loading with SEN/Medical flags, and statutory `AM`/`PM` attendance register submission (`ctx.dal.attendance.upsert_session_batch` + `ctx.plugin_db.exec_batch`).

## Key Files

* [`manifest.json`](file:///home/kieren/Documents/code/optimis/plugins/staff_cover_plugin/manifest.json): Declares `id: "uk.org.optimis.ops.cover"`, `database.alias: "plugin_cover"`, UK GDPR hooks (`export_pupil_data`, `purge_pupil_data`), and interactive RPC endpoints:
  * `load_absent_teacher_timetable` (`dal.groups.read:all`, `mutates: false`)
  * `record_absence_and_assign_cover` (`dal.groups.read:all`, `dal.groups.write:all`, `mutates: true`)
  * `revoke_cover_assignment` (`dal.groups.read:all`, `dal.groups.write:all`, `mutates: true`)
  * `load_cover_class_roster` (`dal.groups.read:own_groups`, `dal.pupils.read:own_groups`, `dal.sen.read:own_groups`, `dal.medical.read:own_groups`, `dal.attendance.read:own_groups`, `mutates: false`)
  * `submit_cover_attendance_batch` (`dal.groups.read:own_groups`, `dal.pupils.read:own_groups`, `dal.attendance.read:own_groups`, `dal.attendance.write:own_groups`, `mutates: true`)
  * `list_cover_assignments` (`dal.groups.read:own_groups`, `mutates: false`)
* [`migrations/001_init.sql`](file:///home/kieren/Documents/code/optimis/plugins/staff_cover_plugin/migrations/001_init.sql): Creates `cover_absences_and_assignments` (storing `absent_staff_id`, `cover_staff_id`, `group_id`, `slot_id`, `cover_date`, `session`, `assigned_role` defaulting to `'COVER_TEACHER'`, `absence_reason`, and `cover_notes`) and `cover_pupil_register_logs` (storing pupil-level cover register notes and marks for UK GDPR SAR export and retention purge).
* [`src/init.lua`](file:///home/kieren/Documents/code/optimis/plugins/staff_cover_plugin/src/init.lua):
  * `load_absent_teacher_timetable(ctx, args)`: Queries [`ctx.dal.groups.get_staff_timetable_slots`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go) for the absent teacher and enriches each affected period with available free staff via [`ctx.dal.groups.list_free_staff_for_period`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go).
  * `record_absence_and_assign_cover(ctx, args)`: Revokes any prior cover teacher on the same slot/date via [`ctx.dal.groups.revoke_staff_assignment`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go), invokes [`ctx.dal.groups.upsert_staff_assignment`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go) (`role = "COVER_TEACHER"`, `effective_from = cover_date`, `effective_to = cover_date`) to dynamically grant the cover teacher temporal `:own_groups` access on `cover_date`, and persists the cover assignment record in `plugin_cover.cover_absences_and_assignments`.
  * `revoke_cover_assignment(ctx, args)`: Revokes the cover teacher's temporal `group_staff_assignments` row via [`ctx.dal.groups.revoke_staff_assignment`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go) and deletes the `plugin_cover.cover_absences_and_assignments` row.
  * `load_cover_class_roster(ctx, args)`: Enforces `:own_groups` access via [`ctx.dal.pupils.list_by_group`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go), enriches active pupils with SEN/Medical flags via [`ctx.dal.pupils.list_sen_and_medical_batch`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go) and persisted marks via [`ctx.dal.attendance.get_group_session`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go), and returns cover lesson instructions from `plugin_cover`.
  * `submit_cover_attendance_batch(ctx, args)`: Submits statutory `AM`/`PM` session marks via [`ctx.dal.attendance.upsert_session_batch`](file:///home/kieren/Documents/code/optimis/internal/host/dal_bindings.go) under `:own_groups` scoping and batch-inserts pupil-level cover register notes in `plugin_cover.cover_pupil_register_logs` via [`ctx.plugin_db.exec_batch`](file:///home/kieren/Documents/code/optimis/internal/host/host.go).
  * `export_pupil_data(ctx, pupil_id)` & `purge_pupil_data(ctx, pupil_id)`: Implements Section 5C / 9.3 UK GDPR SAR export (`redactable_fields = { "register_comment" }`) and retention purge over `plugin_cover.cover_pupil_register_logs`.
* [`ui/dist/index.html`](file:///home/kieren/Documents/code/optimis/plugins/staff_cover_plugin/ui/dist/index.html): Sandboxed micro-frontend (`connect-src 'none'`) subscribing to `window.mis.onPersonaChanged` (`cover-active-persona-badge`) and providing Cover Manager timetable & assignment controls (`load-absent-timetable-btn`, `absence-reason-input`, `cover-notes-input`, `assign-cover-btn`, `cover-assignment-receipt`) and Supply/Cover Teacher class roster & statutory attendance register controls (`load-cover-roster-btn`, `cover-error-banner`, `cover-roster-table`, `submit-cover-attendance-btn`, `cover-attendance-receipt`).
