# Go Command Line & Server Binaries (`cmd`)

This directory contains the Go `main` package entrypoints for the Optimis platform and the Section 10A Plugin Developer Toolchain.

## Implemented Binaries

* [`cmd/mis-server`](file:///home/kieren/Documents/code/optimis/cmd/mis-server/GEMINI.md): Main Go Host Container binary (`./bin/mis-server`) enforcing fail-fast bootstrap validation via single `DATABASE_PATH` (with `--db` flag support), loading all plugins from `PLUGINS_DIR` (or 0 plugins if blank in `.env`) with optional CLI overrides (`--no-plugins` / `--plugins`), providing the Section 7C Local Break-Glass CLI subcommands (`./bin/mis-server config list`, `config get <key>`, `config set <key> <value>`, and `config repair-sso`), and serving the embedded React Host UI Shell, Lua RPC gateway, and Core DAL.
* [`cmd/mis-seed-qa`](file:///home/kieren/Documents/code/optimis/cmd/mis-seed-qa/GEMINI.md): Deterministic synthetic UK All-Through school QA database generator (`npm run seed` with interactive path prompt or positional argument) populating all 45 core tables without reading from `.env`.
* [`cmd/mis-dev-server`](file:///home/kieren/Documents/code/optimis/cmd/mis-dev-server/GEMINI.md): Standalone local host (`./bin/mis-dev-server`) + auto-seeded synthetic school DB + hot-reload mounting for plugin `src/`, `migrations/`, and `ui/`, emitting single-line structured `stdout` logs (`10D`) and supporting persona switching via CLI flag (`--persona`), `?__persona=` URL param, or HTTP header (`X-MIS-Persona`).
* [`cmd/mis-test`](file:///home/kieren/Documents/code/optimis/cmd/mis-test/GEMINI.md): Headless Lua test runner (`./bin/mis-test`) executing plugin `tests/*_test.lua` suites against an isolated synthetic school SQLite fixture with structured single-line `stdout` logs (`type=rpc`, `type=lua_err`, `sqlite_write_hold_ms=`, `type=event_emit`, file/line stack traces).
* [`cmd/mis-verify`](file:///home/kieren/Documents/code/optimis/cmd/mis-verify/GEMINI.md): CI contract & UK GDPR gatekeeper (`./bin/mis-verify`) enforcing manifest/Lua/UI `data-mis-rpc` cross-checks (`MANIFEST_LUA_UI_OK`), offline CSP linting (`CSP_OFFLINE_OK`), Expand-and-Contract SQL migration rules (`MIGRATIONS_OK`), and headless GDPR `export_pupil_data` & `purge_pupil_data` zero-orphan verification (`GDPR_ZERO_ORPHANS_OK`).
* [`cmd/mis-pack`](file:///home/kieren/Documents/code/optimis/cmd/mis-pack/GEMINI.md): Pre-flight `mis-verify` check + Lucide SVG icon extractor (`icon.svg`) + deterministic `.mispkg` archive bundler (`./bin/mis-pack`).
