# `@ukmis/bridge` (`sdk/packages/bridge`)

Lightweight untyped JSON RPC + declarative DOM bridge package (`10C`) for Optimis sandboxed plugin iframes (`<iframe sandbox="allow-scripts">`).

## Files

* [`package.json`](file:///home/kieren/Documents/code/optimis/sdk/packages/bridge/package.json): Package metadata (`@ukmis/bridge`).
* [`index.js`](file:///home/kieren/Documents/code/optimis/sdk/packages/bridge/index.js): Exports `useMisRpc(method, defaultArgs)`, `rpc(method, args)`, `navigate(entityType, params)`, and `DECLARATIVE_ATTRIBUTES` (`data-mis-rpc`, `data-mis-args`, `data-mis-link`).
* [`index.d.ts`](file:///home/kieren/Documents/code/optimis/sdk/packages/bridge/index.d.ts): TypeScript declarations for `useMisRpc` and bridge methods.
