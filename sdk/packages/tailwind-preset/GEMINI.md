# `@ukmis/tailwind-preset` (`sdk/packages/tailwind-preset`)

Official Tailwind CSS preset (`10C`) mapping `--mis-*` school branding, surface, text, border, and accessibility tokens injected into sandboxed plugin iframes on `mis:init`.

## Files

* [`package.json`](file:///home/kieren/Documents/code/optimis/sdk/packages/tailwind-preset/package.json): Package metadata (`@ukmis/tailwind-preset`).
* [`index.js`](file:///home/kieren/Documents/code/optimis/sdk/packages/tailwind-preset/index.js): Exports the Tailwind theme extension mapping `colors.mis.*`, `fontFamily`, and `borderRadius` to `var(--mis-*)`.
